Atualmente, na **Consumer Tecnologia**, atuo com **SQL e Firebird**, investigação de inconsistências e falhas em sistemas e desenvolvimento de scripts Python para conferência de dados.

Também desenvolvo projetos independentes, incluindo aplicações com autenticação, plataformas web e integrações com inteligência artificial.
